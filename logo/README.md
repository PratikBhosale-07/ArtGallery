# Logo Setup Instructions

## Required Logo Files

Please save the following logo files in this directory:

1. **logo-purple.png** - Purple watercolor logo (for Abstract theme)
2. **logo-orange.png** - Orange watercolor logo (for Sculpture theme)
3. **logo-green.png** - Green watercolor logo (for Digital Art theme)
4. **logo-blue.png** - Blue watercolor logo (for Masterpiece theme)

## Logo Specifications

- **Format**: PNG with transparent background
- **Recommended Size**: 400-600px width
- **Color Schemes**:
  - Purple: Matches #8b5cf6 (Abstract slide)
  - Orange: Matches #f59e0b (Sculpture slide)
  - Green: Matches #10b981 (Digital Art slide)
  - Blue: Matches #2563eb (Masterpiece slide)

## How It Works

The website automatically switches between logo colors as the hero carousel changes:

- Blue logo appears with the "masterpiece" slide
- Green logo appears with the "digital art" slide
- Orange logo appears with the "sculpture" slide
- Purple logo appears with the "abstract" slide

The transition is smooth with a 0.5s fade effect.

## File Naming Convention

**IMPORTANT**: Files must be named exactly as shown above for the automatic color switching to work.
